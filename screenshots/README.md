# Screenshots

Espacio preparado para las capturas de este case study. Ninguna captura se publica aquí sin cumplir lo siguiente:

## Requisitos antes de publicar cualquier captura

- [ ] Sanitizada: sin datos reales de clientes, usuarios, montos, cuentas o documentos.
- [ ] Sin endpoints, IPs ni URLs internas visibles.
- [ ] Sin nombres de usuario ni credenciales visibles.
- [ ] Sin información financiera u operativa real.
- [ ] Autorización confirmada para publicar la interfaz real de la app.

Si no existe autorización confirmada para publicar capturas de la interfaz real, la alternativa es **recrear la interfaz con datos ficticios** (por ejemplo, en Figma o similar) y etiquetar la imagen explícitamente como:

> Recreación para portfolio — no es una captura del sistema real.
